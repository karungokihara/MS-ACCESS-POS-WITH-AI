Public Function UX_GoBack()

    On Error Resume Next

    Dim frm As Form

    Set frm = Screen.ActiveForm

    If frm Is Nothing Then Exit Function

    If frm.NewRecord Then
        If frm.Dirty Then frm.Undo
    End If

    If CurrentProject.AllForms("Dashboard").IsLoaded Then
        If Forms("Dashboard").Controls("subNavModule").SourceObject = frm.Name Then
            UX_ShowHome
            Exit Function
        End If
    End If

    DoCmd.Close acForm, frm.Name

End Function

Public Function UX_ShowModule(ByVal formName As String) As Boolean

    On Error GoTo Err_Handler

    Dim frm As Form

    If Not CurrentProject.AllForms("Dashboard").IsLoaded Then
        DoCmd.OpenForm "Dashboard"
    End If

    Set frm = Forms("Dashboard")
    UX_SetHomeCards frm, False
    frm.Controls("subNavModule").SourceObject = formName
    frm.Controls("subNavModule").Visible = True
    UX_FitDashboard
    UX_ShowModule = True
    Exit Function

Err_Handler:
    MsgBox Err.Description, vbExclamation, "Open"
    UX_ShowModule = False

End Function

Public Function UX_ShowHome() As Boolean

    On Error GoTo Err_Handler

    Dim frm As Form

    Set frm = Forms("Dashboard")
    frm.Controls("subNavModule").SourceObject = ""
    frm.Controls("subNavModule").Visible = False
    UX_SetHomeCards frm, True
    UX_ShowHome = True
    Exit Function

Err_Handler:
    UX_ShowHome = False

End Function

Public Sub UX_SetHomeCards(ByVal frm As Form, ByVal showCards As Boolean)

    On Error Resume Next

    Dim ctl As Control

    For Each ctl In frm.Controls
        If ctl.Left > 3300 Then
            If ctl.Name <> "subNavModule" And ctl.Name <> "Label50" Then
                ctl.Visible = showCards
            End If
        End If
    Next ctl

End Sub

Public Function UX_ButtonIn(Optional ByVal frm As Object, Optional ByVal buttonName As String = "")

    On Error Resume Next

    Dim ctl As Control
    Dim other As Control
    Dim parts() As String
    Dim baseL As Long
    Dim baseT As Long
    Dim baseW As Long
    Dim baseH As Long
    Dim newW As Long
    Dim newH As Long

    If frm Is Nothing Or Len(buttonName) = 0 Then Exit Function
    Set ctl = frm.Controls(buttonName)
    If ctl Is Nothing Then Exit Function

    For Each other In frm.Controls
        If other.ControlType = 104 Then
            If other.Name <> ctl.Name Then UX_RestoreButton other
        End If
    Next other

    If Left$(Nz(ctl.Tag, ""), 3) <> "HZ~" Then
        ctl.Tag = "HZ~" & ctl.Left & "~" & ctl.Top & "~" & ctl.Width & "~" & ctl.Height & "~" & ctl.Tag
    End If

    parts = Split(ctl.Tag, "~")
    baseL = CLng(parts(1))
    baseT = CLng(parts(2))
    baseW = CLng(parts(3))
    baseH = CLng(parts(4))

    If ctl.Width <> baseW Then Exit Function

    newW = CLng(baseW * 1.12)
    newH = CLng(baseH * 1.3)
    ctl.FontSize = Nz(ctl.FontSize, 11) + 1
    If ctl.Name = "cmdLogout" Then
        ctl.BackColor = RGB(141, 25, 25)
    Else
        ctl.BackColor = RGB(30, 64, 175)
    End If
    ctl.Width = newW
    ctl.Height = newH
    ctl.Left = baseL - ((newW - baseW) \ 2) + 60
    ctl.Top = baseT - ((newH - baseH) \ 2)
    If ctl.Left < 0 Then ctl.Left = 0
    If ctl.Top < 0 Then ctl.Top = 0

End Function

Public Function UX_ButtonOut(Optional ByVal frm As Object)

    On Error Resume Next

    Dim ctl As Control

    If frm Is Nothing Then Set frm = Screen.ActiveForm
    If frm Is Nothing Then Exit Function

    For Each ctl In frm.Controls
        If ctl.ControlType = 104 Then UX_RestoreButton ctl
        If ctl.ControlType = 112 Then
            If Len(Nz(ctl.SourceObject, "")) > 0 Then UX_ButtonOut ctl.Form
        End If
    Next ctl

End Function

Public Function UX_FitDashboard()

    On Error Resume Next

    Dim frm As Form
    Dim h As Long
    Dim w As Long

    Set frm = Forms("Dashboard")
    h = frm.InsideHeight - frm.Section(1).Height - 60
    w = frm.InsideWidth - 3300
    If h < 4000 Then h = 4000
    If w < 6000 Then w = 6000

    If frm.Section(0).Height < h + 80 Then frm.Section(0).Height = h + 80
    frm.Controls("Box24").Height = h
    frm.Controls("imgBg").Width = frm.InsideWidth
    frm.Controls("imgBg").Height = h + 80
    frm.Controls("subNavModule").Width = w
    frm.Controls("subNavModule").Height = h
    frm.Section(0).Height = h + 80
    If frm.Width < 3300 + w Then frm.Width = 3300 + w

    If frm.Controls("subNavModule").Visible Then
        If Len(Nz(frm.Controls("subNavModule").SourceObject, "")) > 0 Then
            UX_FitForm frm.Controls("subNavModule").Form, w - 360, h - 120
        End If
    End If

End Function

Public Function UX_Logout()

Public Sub UX_FitForm(ByVal frm As Form, ByVal availW As Long, ByVal availH As Long)

    On Error Resume Next

    Dim ctl As Control
    Dim sec As Long
    Dim contentW As Long
    Dim contentH As Long
    Dim secBottom(0 To 2) As Long
    Dim s As Double
    Dim b As Long
    Dim cap As String

    For Each ctl In frm.Controls
        If ctl.ControlType = 104 Then
            cap = LCase$(Trim$(Nz(ctl.Caption, "")))
            If cap = "close" Or cap = "exit" Then ctl.Visible = False
            If frm.Name = "F_SystemSettings" Then
                If ctl.Name = "cmdRefresh" Or ctl.Name = "cmdNextStep" Then ctl.Visible = False
            End If
        End If
    Next ctl

    frm.ScrollBars = 3

    For Each ctl In frm.Controls
        If ctl.Visible Then
            If ctl.Left + ctl.Width > contentW Then contentW = ctl.Left + ctl.Width
            sec = ctl.Section
            If sec >= 0 And sec <= 2 Then
                b = ctl.Top + ctl.Height
                If b > secBottom(sec) Then secBottom(sec) = b
            End If
        End If
    Next ctl

    For sec = 0 To 2
        If secBottom(sec) > 0 Then contentH = contentH + secBottom(sec) + 60
    Next sec

    If contentW = 0 Or contentH = 0 Then Exit Sub

    s = 1
    If availW / contentW < s Then s = availW / contentW
    If availH / contentH < s Then s = availH / contentH
    If s < 0.62 Then s = 0.62
    If s > 0.98 Then Exit Sub

    For Each ctl In frm.Controls
        ctl.Left = CLng(ctl.Left * s)
        ctl.Top = CLng(ctl.Top * s)
        ctl.Width = CLng(ctl.Width * s)
        ctl.Height = CLng(ctl.Height * s)
        ctl.FontSize = CInt(ctl.FontSize * s + 0.4)
        If ctl.FontSize < 8 Then ctl.FontSize = 8
    Next ctl

    For sec = 0 To 2
        If secBottom(sec) > 0 Then frm.Section(sec).Height = CLng(secBottom(sec) * s) + 60
    Next sec

End Sub

Public Sub UX_RestoreButton(ByVal ctl As Control)

    On Error Resume Next

    Dim parts() As String

    If Left$(Nz(ctl.Tag, ""), 3) <> "HZ~" Then Exit Sub
    parts = Split(ctl.Tag, "~")
    If ctl.Width = CLng(parts(3)) Then Exit Sub
    If ctl.Name = "cmdLogout" Then
        ctl.BackColor = RGB(190, 30, 34)
    Else
        ctl.BackColor = RGB(0, 0, 0)
    End If
    ctl.FontSize = ctl.FontSize - 1
    ctl.Left = CLng(parts(1))
    ctl.Top = CLng(parts(2))
    ctl.Width = CLng(parts(3))
    ctl.Height = CLng(parts(4))

End Sub

Public Sub UX_SuppressFormError( _
    ByVal DataErr As Integer, _
    ByRef Response As Integer, _
    ByRef handled As Boolean)

    handled = False

    Select Case DataErr

        Case 7787, 7878, 3197, 2169, 2115, 2501, 3021, 3314

            Response = 0
            handled = True

    End Select

End Sub

Public Sub UX_MarkRequired(ByVal frm As Form, ParamArray controlNames() As Variant)

    On Error Resume Next

    Dim controlName As Variant
    Dim ctl As Control
    Dim lbl As Control
    Dim captionText As String

    For Each controlName In controlNames

        Set ctl = Nothing
        Set lbl = Nothing
        Set ctl = frm.Controls(CStr(controlName))

        If Not ctl Is Nothing Then
            Set lbl = ctl.Controls(0)
        End If

        If Not lbl Is Nothing Then

            captionText = Trim$(lbl.Caption)

            If Len(captionText) > 0 Then

                If Right$(captionText, 1) <> "*" Then
                    lbl.Caption = captionText & " *"
                End If

            End If

        End If

    Next controlName

End Sub

    UX_SqlText = "'" & Replace(Nz(value, vbNullString), "'", "''") & "'"

End Function

Public Function UX_IsInternalCustomer(ByVal customerID As Long) As Boolean

    Dim customerTypeText As String
    Dim customerCodeText As String

    UX_IsInternalCustomer = False

    If customerID <= 0 Then Exit Function

    customerTypeText = Trim$(Nz(DLookup( _
        "CustomerType", "T_Customers", "CustomerID=" & customerID), vbNullString))

    customerCodeText = Trim$(Nz(DLookup( _
        "CustomerCode", "T_Customers", "CustomerID=" & customerID), vbNullString))

    If StrComp(customerTypeText, "Internal", vbTextCompare) = 0 Then
        UX_IsInternalCustomer = True
    ElseIf StrComp(customerCodeText, "INTERNAL", vbTextCompare) = 0 Then
        UX_IsInternalCustomer = True
    End If

End Function

Public Sub UX_EnsureUnit(ByVal unitCode As String, ByVal unitName As String)

    On Error Resume Next

    Dim existingID As Variant
    Dim db As DAO.Database
    Dim rs As DAO.Recordset

    existingID = DLookup("UnitID", "T_Units", "UnitCode=" & UX_SqlText(unitCode))

    If Not IsNull(existingID) Then

        Set db = CurrentDb
        db.Execute _
            "UPDATE T_Units SET UnitName=" & UX_SqlText(unitName) & _
            " WHERE UnitID=" & CLng(existingID) & _
            " AND Len(Trim(Nz(UnitName,'')))=0", _
            dbFailOnError

        Exit Sub

    End If

    Set db = CurrentDb
    Set rs = db.OpenRecordset("T_Units", dbOpenDynaset)

    rs.AddNew
    rs!UnitCode = unitCode
    rs!UnitName = unitName
    rs!Description = unitName
    rs.Update
    rs.Close

    Set rs = Nothing
    Set db = Nothing

End Sub

Public Function UX_ReviewDuplicateItemName( _
    ByVal itemName As String, _
    ByVal itemID As Long, _
    ByVal descriptionText As String) As Boolean

    Dim existingID As Variant
    Dim existingCode As String
    Dim responseValue As VbMsgBoxResult

    UX_ReviewDuplicateItemName = True

    itemName = Trim$(Nz(itemName, vbNullString))

    If Len(itemName) = 0 Then Exit Function

    existingID = DLookup( _
        "ItemID", _
        "T_Items", _
        "UCase$(Trim$(Nz(ItemName,'')))=" & UX_SqlText(UCase$(itemName)) & _
        " AND ItemID<>" & itemID)

    If IsNull(existingID) Then Exit Function

    existingCode = Nz(DLookup( _
        "InternalSKU", "T_Items", "ItemID=" & CLng(existingID)), vbNullString)

    If Len(Trim$(Nz(descriptionText, vbNullString))) = 0 Then

        responseValue = MsgBox( _
            "An item named '" & itemName & "' already exists." & vbCrLf & _
            "Item Code: " & existingCode & vbCrLf & vbCrLf & _
            "Yes: open the existing item so you can edit it." & vbCrLf & _
            "No: stay here and enter a description that distinguishes this item.", _
            vbYesNo + vbExclamation, _
            "Duplicate Item Name")

        If responseValue = vbYes Then

            On Error Resume Next
            DoCmd.OpenForm "F_ItemSetup", acNormal, , "ItemID=" & CLng(existingID)
            On Error GoTo 0

        End If

        UX_ReviewDuplicateItemName = False

    Else

        MsgBox _
            "An item named '" & itemName & "' already exists." & vbCrLf & _
            "Item Code: " & existingCode & vbCrLf & vbCrLf & _
            "This item will be saved because a description was entered to tell it apart.", _
            vbInformation, _
            "Similar Item Name"

        UX_ReviewDuplicateItemName = True

    End If

End Function

Public Sub UX_FillLineFromItem(ByVal frm As Form)

    On Error Resume Next

    Dim itemControlName As String
    Dim unitControlName As String
    Dim priceControlName As String
    Dim descriptionControlName As String
    Dim quantityControlName As String
    Dim codeControlName As String
    Dim itemIDValue As Long
    Dim baseUnitID As Variant
    Dim salesPrice As Variant
    Dim itemName As Variant
    Dim itemCode As Variant

    itemControlName = UX_FirstControl(frm, "ItemID", "cboItemID")

    If Len(itemControlName) = 0 Then Exit Sub
    If IsNull(frm.Controls(itemControlName).Value) Then Exit Sub

    itemIDValue = CLng(frm.Controls(itemControlName).Value)

    baseUnitID = DLookup("BaseUnitID", "T_Items", "ItemID=" & itemIDValue)
    salesPrice = DLookup("DefaultSalesPrice", "T_Items", "ItemID=" & itemIDValue)
    itemName = DLookup("ItemName", "T_Items", "ItemID=" & itemIDValue)
    itemCode = DLookup("InternalSKU", "T_Items", "ItemID=" & itemIDValue)

    unitControlName = UX_FirstControl(frm, "UnitID", "cboUnitID", "txtUnitID")

    If Len(unitControlName) > 0 Then

        If Not IsNull(baseUnitID) Then

            If IsNull(frm.Controls(unitControlName).Value) Then
                frm.Controls(unitControlName).Value = CLng(baseUnitID)
            ElseIf Nz(frm.Controls(unitControlName).Value, 0) = 0 Then
                frm.Controls(unitControlName).Value = CLng(baseUnitID)
            End If

        End If

    End If

    priceControlName = UX_FirstControl(frm, "UnitPrice", "txtUnitPrice")

    If Len(priceControlName) > 0 Then

        If Not IsNull(salesPrice) Then

            If Nz(frm.Controls(priceControlName).Value, 0) = 0 Then
                frm.Controls(priceControlName).Value = salesPrice
            End If

        End If

    End If

    descriptionControlName = UX_FirstControl( _
        frm, "LineDescription", "txtLineDescription", "ItemDescription", "DescriptionSnapshot")

    If Len(descriptionControlName) > 0 Then

        If Len(Trim$(Nz(frm.Controls(descriptionControlName).Value, vbNullString))) = 0 Then
            frm.Controls(descriptionControlName).Value = Nz(itemName, vbNullString)
        End If

    End If

    codeControlName = UX_FirstControl(frm, "ItemCode", "txtItemCode", "SupplierPartNumber")

    If Len(codeControlName) > 0 Then

        If Len(Trim$(Nz(frm.Controls(codeControlName).Value, vbNullString))) = 0 Then
            frm.Controls(codeControlName).Value = Nz(itemCode, vbNullString)
        End If

    End If

    If frm.NewRecord Then

        quantityControlName = UX_FirstControl( _
            frm, "QuantityOrdered", "txtQuantityOrdered", "Quantity", "txtQuantity", "OrderedQuantity")

        If Len(quantityControlName) > 0 Then

            If Nz(frm.Controls(quantityControlName).Value, 0) = 0 Then
                frm.Controls(quantityControlName).Value = 1
            End If

        End If

    End If

End Sub

Public Function UX_AdjustStockQuantity( _
    ByRef Quantity As Double, _
    ByVal reasonText As String) As Boolean

    reasonText = Trim$(Nz(reasonText, vbNullString))

    If Abs(Quantity) < 0.0000001 Then

        MsgBox "Enter the quantity.", vbExclamation, "Quantity Required"
        UX_AdjustStockQuantity = False
        Exit Function

    End If

    If StrComp(reasonText, "Negative Adjustment", vbTextCompare) = 0 _
        Or InStr(1, reasonText, "Negative", vbTextCompare) > 0 Then

        Quantity = -Abs(Quantity)

    ElseIf Quantity < 0 Then

        MsgBox _
            "Quantity must be greater than zero, unless the reason is Negative Adjustment.", _
            vbExclamation, _
            "Invalid Quantity"

        UX_AdjustStockQuantity = False
        Exit Function

    End If

    UX_AdjustStockQuantity = True

End Function

Public Function UX_BillToAddress(ByVal customerID As Long) As String

    Dim addressText As String

    If customerID <= 0 Then Exit Function

    addressText = Trim$(Nz(DLookup( _
        "BillingAddress", "T_Customers", "CustomerID=" & customerID), vbNullString))

    If Len(addressText) = 0 Then

        addressText = Trim$(Nz(DLookup( _
            "BillingAddress1", "T_Customers", "CustomerID=" & customerID), vbNullString))

        If Len(Trim$(Nz(DLookup("BillingCity", "T_Customers", "CustomerID=" & customerID), vbNullString))) > 0 Then
            addressText = addressText & vbCrLf & _
                Trim$(Nz(DLookup("BillingCity", "T_Customers", "CustomerID=" & customerID), vbNullString))
        End If

    End If

    If Len(addressText) = 0 Then

        addressText = Trim$(Nz(DLookup( _
            "ShippingAddress", "T_Customers", "CustomerID=" & customerID), vbNullString))

    End If

    UX_BillToAddress = addressText

End Function

Public Function UX_PrintActive( _
    ByVal reportName As String, _
    ByVal idControl As String, _
    ByVal documentTitle As String) As Boolean

    On Error GoTo Err_Handler

    Dim frm As Form
    Dim recordID As Long

    Set frm = Screen.ActiveForm

    If frm.Dirty Then
        frm.Dirty = False
    End If

    recordID = CLng(Nz(frm.Controls(idControl).Value, 0))

    If recordID <= 0 Then

        MsgBox _
            "Save this " & documentTitle & " before printing.", _
            vbExclamation, _
            documentTitle

        Exit Function

    End If

    UX_PrintDocument reportName, recordID, documentTitle
    UX_PrintActive = True

    Exit Function

Err_Handler:

    MsgBox _
        "The " & documentTitle & " could not be printed." & vbCrLf & vbCrLf & _
        Err.Description, _
        vbExclamation, _
        documentTitle

End Function

Public Sub UX_PrintDocument( _
    ByVal reportName As String, _
    ByVal recordID As Long, _
    ByVal documentTitle As String)

    On Error GoTo Err_Handler

    Dim folderPath As String
    Dim filePath As String
    Dim whereText As String

    folderPath = Environ$("USERPROFILE") & "\Documents\Inventory System PDFs\" & documentTitle
    UX_EnsureFolder Environ$("USERPROFILE") & "\Documents\Inventory System PDFs"
    UX_EnsureFolder folderPath

    filePath = folderPath & "\" & UX_CleanFileName(documentTitle) & "_" & CStr(recordID) & ".pdf"
    whereText = "[InvoiceID]=" & recordID

    If CurrentProject.AllReports(reportName).IsLoaded Then
        DoCmd.Close acReport, reportName, acSaveNo
    End If

    DoCmd.OpenReport reportName, acViewPreview, , whereText, acHidden

    DoCmd.OutputTo acOutputReport, reportName, acFormatPDF, filePath, True

    DoCmd.Close acReport, reportName, acSaveNo

    MsgBox documentTitle & " PDF created." & vbCrLf & vbCrLf & filePath, vbInformation, documentTitle

    Exit Sub

Err_Handler:

    On Error Resume Next
    DoCmd.Close acReport, reportName, acSaveNo
    On Error GoTo 0

    MsgBox _
        "The " & documentTitle & " PDF could not be created." & vbCrLf & vbCrLf & _
        Err.Description, _
        vbExclamation, _
        documentTitle

End Sub

Public Function UX_AttachToCurrentForm( _
    ByVal idControl As String, _
    ByVal documentType As String) As Boolean

    On Error GoTo Err_Handler

    Dim frm As Form
    Dim documentID As Long
    Dim pickedPath As String
    Dim savedPath As String
    Dim fileNameText As String
    Dim db As DAO.Database
    Dim rs As DAO.Recordset

    Set frm = Screen.ActiveForm

    If frm.Dirty Then
        frm.Dirty = False
    End If

    documentID = CLng(Nz(frm.Controls(idControl).Value, 0))

    If documentID <= 0 Then

        MsgBox "Save the record before attaching a file.", vbExclamation, "Attach File"
        Exit Function

    End If

    pickedPath = UX_PickFile()

    If Len(pickedPath) = 0 Then Exit Function

    savedPath = UX_CopyIntoFolder(pickedPath, documentType)
    fileNameText = Mid$(pickedPath, InStrRev(pickedPath, "\") + 1)

    Set db = CurrentDb
    Set rs = db.OpenRecordset("T_DocumentAttachments", dbOpenDynaset)

    rs.AddNew
    UX_SetRsField rs, "DocumentType", documentType
    UX_SetRsField rs, "DocumentID", documentID
    UX_SetRsField rs, "FileName", fileNameText
    UX_SetRsField rs, "FilePath", savedPath
    UX_SetRsField rs, "AttachmentNotes", "Uploaded client document"
    UX_SetRsField rs, "CreatedOn", Now()
    rs.Update
    rs.Close

    On Error Resume Next
    frm.Controls("txtSourceFilePath").Value = savedPath

    If StrComp(documentType, "CustomerPO", vbTextCompare) = 0 Then

        db.Execute _
            "UPDATE T_CustomerPOs SET SourceFilePath=" & UX_SqlText(savedPath) & _
            " WHERE CustomerPOID=" & documentID, _
            dbFailOnError

    End If

    On Error GoTo Err_Handler

    MsgBox "File attached." & vbCrLf & vbCrLf & savedPath, vbInformation, "Attach File"
    UX_AttachToCurrentForm = True

    Exit Function

Err_Handler:

    MsgBox _
        "The file could not be attached." & vbCrLf & vbCrLf & Err.Description, _
        vbExclamation, _
        "Attach File"

End Function

Public Function UX_CopyIntoFolder( _
    ByVal sourcePath As String, _
    ByVal documentType As String) As String

    Dim folderPath As String
    Dim fileNameText As String
    Dim destinationPath As String

    folderPath = Environ$("USERPROFILE") & "\Documents\Inventory System PDFs\Attachments\" & documentType
    UX_EnsureFolder Environ$("USERPROFILE") & "\Documents\Inventory System PDFs"
    UX_EnsureFolder Environ$("USERPROFILE") & "\Documents\Inventory System PDFs\Attachments"
    UX_EnsureFolder folderPath

    fileNameText = Mid$(sourcePath, InStrRev(sourcePath, "\") + 1)
    destinationPath = folderPath & "\" & Format$(Now(), "yyyymmdd_hhnnss") & "_" & fileNameText

    FileCopy sourcePath, destinationPath
    UX_CopyIntoFolder = destinationPath

End Function

Public Sub UX_EnsureFolder(ByVal folderPath As String)

    On Error Resume Next

    If Len(Dir$(folderPath, vbDirectory)) = 0 Then
        MkDir folderPath
    End If

End Sub

Public Function UX_CleanFileName(ByVal fileNameText As String) As String

    Dim badCharacters As Variant
    Dim oneCharacter As Variant

    badCharacters = Array("\", "/", ":", "*", "?", """", "<", ">", "|")

    For Each oneCharacter In badCharacters
        fileNameText = Replace(fileNameText, CStr(oneCharacter), "_")
    Next oneCharacter

    UX_CleanFileName = Trim$(fileNameText)

End Function

Public Function UX_WarehouseLocationNames(ByVal WarehouseID As Long) As String

    On Error GoTo Err_Handler

    Dim db As DAO.Database
    Dim rs As DAO.Recordset
    Dim names As String

    UX_WarehouseLocationNames = ""
    If WarehouseID <= 0 Then Exit Function

    Set db = CurrentDb
    Set rs = db.OpenRecordset( _
        "SELECT LocationName FROM T_Locations " & _
        "WHERE WarehouseID=" & WarehouseID & " AND Len(Trim(Nz(LocationName,'')))>0 " & _
        "ORDER BY LocationName")

    Do While Not rs.EOF
        If Len(names) > 0 Then names = names & ", "
        names = names & Nz(rs!LocationName, "")
        rs.MoveNext
    Loop

    rs.Close
    UX_WarehouseLocationNames = names

    Set rs = Nothing
    Set db = Nothing
    Exit Function

Err_Handler:
    UX_WarehouseLocationNames = ""

End Function
